# 📊 Monday BI Agent

An AI-powered Business Intelligence Dashboard built with **Python**, **Streamlit**, **Monday.com API**, and **OpenAI** to analyze sales pipelines, work orders, financial metrics, and operational performance.

---

## 🚀 Features

- 📈 Executive Business Dashboard
- 💼 Sales Pipeline Analytics
- 📋 Work Order Analysis
- 💰 Financial Performance Metrics
- ⚙️ Operational KPIs
- 🤖 AI Business Assistant (OpenAI)
- 📊 Interactive Charts
- 🔄 Real-time Data Processing
- ☁️ Monday.com API Integration

---

## 🛠️ Tech Stack

- Python 3.11+
- Streamlit
- Pandas
- Plotly
- OpenAI API
- Monday.com API
- Requests
- dotenv

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/HarshaVardhanReddyGujjula/Monday-BI-Agent.git
```

Move into the project

```bash
cd Monday-BI-Agent
```

Install dependencies

```bash
pip install -r requirements.txt
```

---

## 🔑 Environment Variables

Create a `.env` file.

```env
MONDAY_API_TOKEN=YOUR_TOKEN

OPENAI_API_KEY=YOUR_API_KEY

OPENAI_MODEL=gpt-4o
```

---

## ▶️ Run Dashboard

```bash
streamlit run dashboard.py
```
